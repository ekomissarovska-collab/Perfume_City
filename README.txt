Готовый index.html для GitHub Pages с прямой отправкой заказов через Telegram Bot API.
Google Apps Script не используется.

Перед публикацией:
1. Отзовите токен, который уже показывали в публичном HTML/скриншотах, через @BotFather.
2. Создайте новый токен.
3. В index.html замените значение ВСТАВТЕ_НОВИЙ_ТОКЕН_БОТА на новый токен.
4. Проверьте TG_CHAT_ID (сейчас 443675424) и нажмите Start у бота.
5. Замените index.html в репозитории GitHub и сделайте Commit changes.

ВАЖНО: токен в HTML на GitHub Pages виден всем. Это только прямой тестовый вариант; для магазина безопаснее серверная функция с секретом в переменных окружения.
