ПРЯМАЯ ОТПРАВКА ЗАКАЗОВ В TELEGRAM (GitHub Pages)

ВНИМАНИЕ: этот вариант помещает токен бота в публичный HTML. Любой посетитель сможет его увидеть и использовать. Для реального магазина не рекомендуется. Токен, ранее опубликованный в исходном HTML, нужно отозвать в @BotFather и создать новый.

1. Открой index.html.
2. Найди:
   const TG_BOT_TOKEN = 'ВСТАВТЕ_НОВИЙ_ТОКЕН_БОТА';
3. Замени текст на новый токен, который создал через @BotFather.
4. Проверь TG_CHAT_ID. Сейчас там оставлен ID чата из твоего исходного кода: 443675424.
5. Убедись, что открыл бота в Telegram и нажал Start.
6. Загрузи index.html в GitHub-репозиторий и дождись публикации GitHub Pages.
7. Сделай тестовый заказ.

Если не работает:
- проверь, что токен новый и без пробелов;
- убедись, что TG_CHAT_ID — ID личного чата именно с твоим аккаунтом;
- проверь, что нажала Start у бота;
- открой DevTools браузера (F12) -> Console/Network для ошибки Telegram API.

Безопасный вариант: хранить токен в серверной функции/обработчике, а не в HTML.
