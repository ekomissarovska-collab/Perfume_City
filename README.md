# Telegram-заказы для сайта на GitHub Pages

Этот вариант подходит для GitHub Pages: он использует Google Apps Script как небольшой сервер-посредник. Сам GitHub Pages не может запускать `server.js`.

## 1. Сначала защитите бота
Токен бота ранее находился в публичном HTML-коде. В Telegram откройте `@BotFather`, отзовите старый токен и создайте новый. Не публикуйте новый токен в репозитории.

## 2. Создайте Apps Script
1. Откройте https://script.google.com/ и создайте новый проект.
2. Откройте файл `Code.gs` из этого архива, скопируйте его содержимое в редактор Apps Script вместо стартового кода.
3. В Apps Script откройте **Project Settings** (значок шестерёнки) → **Script Properties** → **Add script property** и добавьте:
   - `TG_BOT_TOKEN` = ваш НОВЫЙ токен бота
   - `TG_CHAT_ID` = `443675424` (или актуальный ID чата, куда должны приходить заказы)
4. Нажмите **Deploy** → **New deployment** → выберите тип **Web app**.
5. В поле **Execute as** выберите **Me**; в **Who has access** выберите **Anyone**. Нажмите **Deploy** и разрешите запрошенные доступы.
6. Скопируйте URL веб-приложения, который заканчивается на `/exec`.

## 3. Подключите сайт
1. В `index.html` найдите строку:
   `const ORDER_ENDPOINT = 'ВСТАВТЕ_URL_GOOGLE_APPS_SCRIPT';`
2. Замените текст внутри кавычек на скопированный URL `/exec`.
3. Загрузите обновлённый `index.html` в свой GitHub-репозиторий и дождитесь обновления GitHub Pages.

## 4. Проверьте
- Откройте бота в Telegram и нажмите **Start** (если это личный чат).
- Сделайте тестовый заказ на сайте.
- Проверьте Telegram.
- Если изменяли `Code.gs` после публикации, откройте **Deploy → Manage deployments → Edit** и создайте новую версию развертывания.

## Важное ограничение
В браузере используется `mode: 'no-cors'`, потому что Apps Script не даёт обычным страницам читать ответ через CORS. Поэтому сайт не может достоверно определить, принял ли Telegram заказ: после отправки обязательно проверьте чат. Если сообщения нет, проверьте URL `/exec`, Script Properties, права доступа и логи Apps Script (**Executions**).
